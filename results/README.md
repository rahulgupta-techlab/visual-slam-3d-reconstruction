# Results

The TUM fallback benchmark has been run on fr1_xyz and fr1_desk; KITTI stereo runs are still pending. See [metrics.md](metrics.md) for the numbers, plots and how to interpret them.

- `*_estimated.txt` — estimated trajectories in TUM format, as produced by `scripts/run_vo.py`.
- `*_ate.log`, `*_rpe.log` — raw evo output for each completed evaluation.
- `metrics_<dataset>.md` — tables written by `scripts/evaluate.py`.
- Plots are in [../docs/](../docs/).
